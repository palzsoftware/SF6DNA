# 攻略手順の技照合仕様 v1（①②共通）2026-11-20
実装: `sf6dna_step_matcher_v1.py`（決定的・推測なし。入力＝公式TXT canonical＋確定別名辞書V3の単一技行のみ）

## カード判定
- MATCHED: 自キャラの全手順が「技（公式1行に一意）」「語彙のみ」「システム行動」のいずれか
- NOT_MATCHED: 自キャラ手順に1つでもHOLDがある → 注記「一部の手順は技IDを特定できていない」
- COUNTER_TARGET_ONLY: 手順が相手の技のみ（対策対象。技照合の対象外）

## 手順の処理順
1. 「相手の技：」で始まる → OPPONENT_MOVE（対策対象として別管理、OPPONENT_MOVE_STEPS_FOR_COUNTER.csv）
2. 前置語彙を除去: キャンセルドライブラッシュ/キャンセルラッシュ/Cラッシュ/CDR/CR → DRIVE_RUSH_CANCEL、パリィドライブラッシュ/パリィラッシュ/生ラッシュ → DRIVE_RUSH_PARRY、ドライブラッシュ/ラッシュ/DR＋技 → DRIVE_RUSH_UNSPECIFIED
3. 条件語彙を除去: PC/CH/パニカン/パニッシュカウンター（括弧有無とも）、空振り、最終持続重ね、持続重ね/持続当て、重ね、最速、仕込み、遅らせ/ディレイ、×n、壁
4. 残りが空 → VOCAB_ONLY／システム行動表（歩き・微歩き・ガード・前ステ・バックステップ・各ジャンプ・各ラッシュ単独・ドライブパリィ）に一致 → SYSTEM_ACTION（技IDではない）
5. 技の解決（一意の場合のみMOVE）: DI＝公式ドライブインパクト行／SA1〜3・CA＝段・Lv・括弧版を除き1行のみ／公式名完全一致（NFKC・空白除去、末尾括弧の別名表記も可）／確定別名（単一技）／明示数字または位置語（立ち=5・しゃがみ/屈=2・前=6・後ろ=4）＋強度ボタン→公式ラベル／「数字ボタン（技名）」は数字ボタンで解決／前・後ろ投げ＝公式コマンド（N or 6／4 + LPLK）
6. それ以外はHOLD: 位置未指定のボタン単体（強K・中P）、同名の公式行が複数（段・版・派生を特定できない）、強度未指定ファミリー、通称・部分一致、SA/CAの段違いが複数

## 禁止
