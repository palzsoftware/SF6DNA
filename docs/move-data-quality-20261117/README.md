## 主要な発見

### 1. DB値の連結破損（確定・修正候補31件）
ブランカ9件・エドモンド本田22件の `active`（持続）が「全体範囲」と「公式値」が区切りなしで連結されています。
例: `8-148-9, 11-14`（=`8-14` + `8-9, 11-14`）。DB値の末尾が公式TXT値と完全一致するため、修正候補値は「DB値から先頭の全体範囲を除いた文字列」です。
公開画面にも同じ値が出ている可能性があります（**推定**。DB/本番画面は未確認）。

### 2. キャミィSA2 コマンド P/K 矛盾（HOLD・公式照合待ち）
| 出典 | キラービースピン | エアキラービースピン |
|---|---|---|
| DB/fixture `cammy-sa2` / `cammy-sa2-air` | `214214K` | `j.214214K` |
| 公式TXT 内部ラベル `name` | `(SA2_214214K)` | `(SA2_AIR_214214K)` |
| 公式TXT 表示コマンド `command` | `21424 \| 24214 + LP \| MP \| HP`（**P**） | `（前ジャンプ中に）… + LP \| MP \| HP`（**P**） |

- 公式TXT全2673行のうち、内部ラベルと表示コマンドのP/Kが食い違うのはこの2行のみ（比較可能37行中）。
- 表示コマンド欄はユーザー向け表記、内部ラベルは開発用識別子と考えられ、**DBの`214214K`が誤りの可能性が高い（推測）**。
- CAPCOM公式ページ（`streetfighter.com/6/ja-jp/character/cammy/movelist` / `frame`）はこの作業環境から到達できず照合未完了。公式ページで確認できるまで修正しません。
- 確定した場合の最小修正: DBの `cammy-sa2` / `cammy-sa2-air` のClassicコマンド2行のみ（技ID・slugは不変）。

### 3. ディージェイのslug不一致（HOLD・WS5担当の再生成が必要）
WS5候補のキーは `deejay`、アプリ/DBのslugは `dee-jay`。`getWs5TxtPreviewCandidate('dee-jay')` は常に `null` となり、ディージェイだけ公式TXT接続が効きません。さらに識別子対応付けも0/106件です。ローカル開発専用機能のため本番影響はありません。
単純なエイリアス追加では106行がすべて新規技として既存97技に重複追加されるため、候補生成時にslugを `dee-jay` で再生成する必要があります。
