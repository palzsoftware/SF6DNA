# PHASE6_DICTIONARY_REDESIGN.md

キャラクター図鑑・プレイヤー図鑑の全面リニューアルに向けた現状分析・設計書です。**まだ実装していません。**

## ■現状評価

### キャラクター図鑑

| 項目 | 現状 |
|---|---|
| UI | 一覧はカードグリッド。検索ボックス+8種の「プレイタイプ」フィルターボタン |
| 導線 | 一覧→詳細のみ。詳細ページから他機能(練習メニュー・比較等)への横の導線が無い |
| 検索・フィルター | プレイタイプ(バランス型/パワー型等)による絞り込みのみ。難易度・使用ゲージ等の軸は無い |
| カードデザイン | Phase1のDesign System適用済みだが、一覧カードの情報量は「画像+名前」程度に限定的 |
| 詳細ページ | ヒーロー(能力チャート)/コンセプト/ステータス/長所短所/向いている人/動画/有利不利/関連キャラ/使用プレイヤー、と**情報量は非常に豊富** |
| 動画導線 | 初心者/対戦/コンボ/立ち回り/上達の5タブでAPI自動取得(Phase3-Bで実装済み) |
| 初心者への価値 | 難易度・「向いている人」・初心者向け動画タブがあり**価値は高い** |
| 中級者への価値 | 有利不利(対策キャラ)・立ち回り動画があり一定の価値はあるが、**「自分が使うキャラの強化」という視点の情報が少ない** |
| 上級者への価値 | フレームデータ・コンボの詳細(始動条件・ダメージ効率等)が無く、**現状ほぼ価値を提供できていない** |

### プレイヤー図鑑

| 項目 | 現状 |
|---|---|
| UI | Phase4-Bまでの拡張で、ピックアップ4行(最初に見るべき/大会実績/攻め得意/守り堅実)+今日のおすすめ+検索+一覧、と**情報量は多い** |

| お気に入り | Phase4-Bで実装済み(キャラ・選手・動画・FAQ) |
| 今日のおすすめ | Phase4-Bで実装済み(お気に入り優先ロジック) |

## ■問題点

### ①UXデザイナー視点

- **迷わないか**: キャラクター詳細から「では次に何を見ればいいか」の導線が弱い(関連キャラは出るが、練習メニュー・比較への接続が無い)
- **情報量**: プレイヤー図鑑の一覧ページは、ピックアップ4行+今日のおすすめ+検索+一覧、と**スクロール量が非常に多い**
- **毎日開きたくなるか**: 「今日のおすすめ」は実装済みだが、**それ以外の9割の情報は毎日同じ**。図鑑としての「調べ物」機能に終始しており、再訪を積極的に促す仕掛けが薄い

### ②プロダクトデザイナー視点

- **統一感**: キャラクター詳細ページ(`character.css`相当、Phase1以前のスタイル)と、Phase3-B以降に追加した「今日のおすすめ」カード(Design System準拠)が**同一ページ内でトーンが混在**しています
- **完成度**: 情報量は競合の攻略サイトに劣らない水準まで来ていますが、**「見せ方」が情報の羅列に近く、ブランドとしての個性が薄い**

### ③SF6プレイヤー視点

- **初心者**: 難易度・向いている人・初心者動画が揃っており満足度は高いはずですが、**「結局何を使えばいいか」の最終的な後押し(診断結果との接続)が弱い**
- **中級者**: 有利不利は分かるが、**「なぜ不利なのか」「どう対策するか」の具体まで踏み込めていない**(データが無いため現状は仕方ない部分)
- **上級者**: フレームデータ・詳細なコンボレシピ(始動〜ダメージ〜派生)が無く、**このページを毎日見る理由が無い**というのが最も大きな課題です

### ④Webサービスとしての評価

- **攻略サイトとして**: 基本情報は揃っているが、上級者向けの深い情報(フレーム等)が無いため**中級者止まり**の攻略サイトです
- **ゲーム図鑑として**: ビジュアル面(カード一覧のインパクト)に伸びしろがあります
- **学習サイトとして**: 練習メニュー・診断との連携という他サイトに無い強みがありますが、**図鑑ページ単体では学習動線が完結していません**(図鑑を見た後、練習に繋がる導線が無い)

---

## ■改善案(既存データのみで実現可能なものに限定)

1. **キャラクター詳細→練習メニューへの導線追加**: そのキャラが該当する診断タイプの練習メニューへリンクする(`trainingMenuData`との接続。新規データ不要)
2. **キャラクターカードの情報密度向上**: 一覧カードに`difficulty`(難易度★)・`type`(プレイタイプ)を追加表示するだけで、実データのみで一覧の情報価値が上がります
3. **プレイヤー一覧の情報整理**: ピックアップ4行を**タブ切り替え式**にまとめ、常時表示による情報過多を解消(データは増やさず見せ方のみ変更)
4. **プレイヤー詳細⇄キャラクター詳細の相互リンク**: 選手の`main`(使用キャラ)フィールドは既に存在するため、**リンクを追加するだけ**で双方向導線が作れます
5. **「使用キャラ別」フィルターの追加**: プレイヤー一覧に、既存の`main`フィールドを使った絞り込みを追加(新規データ不要)
6. **キャラクター詳細の「上級者向け」の正直な範囲設定**: フレームデータは無いため無理に作らず、代わりに**「対戦動画」タブと「有利不利」情報を上級者導線として明確に位置づけ直す**(ラベリングの変更のみ)

## ■UI改善案

- カードのクリップ形状・トークンをキャラクター/プレイヤー詳細ページ全体に適用し、Phase3-B以降のページとのトーンを統一
- 難易度は★アイコン(Design Systemの色トークン準拠)で統一表示
- 「今日のおすすめ」の存在感を、詳細ページも含めて全体的に強化(現状トップページのみ)

## ■UX改善案

- キャラクター詳細の末尾に「次にすること」導線(練習メニュー/比較/使用プレイヤー)をまとめて配置し、迷わず次の行動に移れるようにする
- プレイヤー一覧のピックアップをタブ化し、スクロール量を削減
- 相互リンク(キャラ⇄プレイヤー)により、「調べ物」から「回遊」への行動変化を促す

---

## ■優先順位

| 優先度 | 内容 | 理由 |
|---|---|---|
| 高 | キャラ⇄プレイヤーの相互リンク | 既存データのみで実現可能、実装コストが低く、回遊率向上への効果が大きい |
| 高 | キャラクター詳細→練習メニューへの導線 | 既存の`trainingMenuData`と接続するだけ。学習サイトとしての完結性が上がる |
| 中 | カード情報密度の向上(難易度・タイプ表示) | 実データのみ、低コスト |
| 中 | プレイヤー一覧のタブ化(情報整理) | UI変更のみ、データ変更不要 |
| 中 | 使用キャラ別フィルター(プレイヤー一覧) | 既存`main`フィールド活用 |
| 低 | 上級者向けの深い情報(フレームデータ等) | **実データが存在しないため、今回のスコープでは対応不可**。データ整備自体が別プロジェクトになります |

## ■実装ロードマップ(承認後、Phase6として)

1. **Phase6-A**: 相互リンク(キャラ⇄プレイヤー)、練習メニューへの導線追加(データ接続のみ、リスク最小)
2. **Phase6-B**: カード情報密度向上(難易度・タイプ表示)、プレイヤー一覧のタブ化
3. **Phase6-C**: 使用キャラ別フィルターの追加
4. **Phase6-D**: デザイントーンの統一(Phase5で保留したCSS整理と合わせて実施するのが効率的)

## ■今回あえて提案しなかったこと

- フレームデータ・詳細コンボレシピ等、**実データが存在しない上級者向け機能は提案していません**(捏造禁止の方針を遵守)
- ランキングのAPI化・バックエンド連携も対象外としました
- 新しいlocalStorageキーの追加は最小限(使用キャラフィルターは既存`main`フィールドの参照のみで新規保存は不要)に留めています
