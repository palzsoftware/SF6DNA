# PROJECT_HANDOFF.md

SF6DNA プロジェクト引き継ぎ資料です。Phase1〜Phase5の実装、Phase6の設計までを完了した時点でのスナップショットです。

作成日: 2026-07-31

---

## ■現在の完成状況

「診断ツール」から「初心者が毎日開きたくなるSF6総合ポータルサイト」への進化を目標に、Phase1(ホーム)〜Phase5(リファクタリング)まで実装が完了しています。Phase6(キャラクター/プレイヤー図鑑の全面リニューアル)は**設計のみ完了、実装は未着手**です。

サイトはビルド不要の静的HTML/CSS/JS(GitHub Pages配信想定)、外部の動画検索API(バックエンド別リポジトリ、URLのみ参照)、localStorageのみでユーザーデータを管理する構成です。

## ■引き継ぎ時に注意すべき点

1. **Phase1(ホームページ)は凍結中**です。変更する場合は必ず「重大なバグ修正」か「明示的な承認」を得てから行ってください
2. **「存在しないデータを捏造しない」方針を一貫して守っています**。新しい担当者・AIが引き継ぐ際も、この方針を最優先にしてください(特にランキング・大会情報・プレイヤー分類機能で誘惑されやすい箇所です)
3. **開発フロー**: 調査→設計→実装→自己レビュー→報告、を徹底してきました。大きな変更ほど、実装前に「変更対象ファイル・変更内容・影響範囲」を提示する運用を継続することを推奨します
4. **ZIP作成・報告形式**: 開発途中は基本的にZIPを作成せず文章報告のみで進める運用でした(Claude Codeの利用制限を考慮したもの)。今後も同様の運用が推奨されます
5. **`docs/`配下のドキュメントが正式な記録**です。特に`DESIGN_SYSTEM.md`(デザインルール)・`DATA_ISSUES.md`(データ不整合の管理台帳)・`KNOWN_ISSUES.md`・`TECH_DEBT.md`は継続的に更新してください
6. **改行コード(CRLF)の一貫性に注意**: 本プロジェクトのHTMLファイルはCRLFで統一されています。Pythonのテキストモードでの一括編集はLFに変換してしまうことがあるため、バイナリモードでの編集を推奨します(過去に複数回、この問題が発生し都度修正しました)
7. **Chart.js等の外部CDN失敗時の耐障害性**に注意してください。過去に1件、CDN読み込み失敗が原因で無関係な機能まで停止するバグが見つかっています。新しい外部ライブラリを追加する際はtry/catchでの保護を徹底してください
