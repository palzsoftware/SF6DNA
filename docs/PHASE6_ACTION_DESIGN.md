# PHASE6_ACTION_DESIGN.md

前回の`PHASE6_DICTIONARY_REDESIGN.md`(情報整理中心の分析)への追補です。今回は**「見た後に何をしたくなるか」という行動導線の設計**に焦点を当てます。

---

## ■現状評価(追加分)

前回の分析は「情報の見せ方」が中心でしたが、今回改めて確認したところ、**キャラクター詳細・プレイヤー詳細のいずれも、ページの終わり(スクロール最下部)に「次の行動」を促す設計が一切無い**ことが分かりました。関連キャラクター・使用プレイヤーの一覧はありますが、これは「関連情報の提示」であって「次にやることの提案」にはなっていません。

## ■重要な事実確認: 「誰から学ぶか」分類の実現可能性

ご提案の「読み合いが上手い」「コンボが参考になる」等の分類について、実データを調査した結果、**以下の制約が判明しました**。

| データ項目 | 充足率 | 分類への使用可否 |
|---|---|---|
| `style`(プレイスタイル) | 91名中35名(約38%) | △ 使えるが、**6割強の選手は該当データが無い** |
| `learningCategories`(8軸の学習ポイント、`reading`/`offense`等) | **91名中わずか1名(ときど選手)** | **✕ 現状は事実上使えません** |
| `achievements`(大会実績) | ほぼ全員 | ○ 使用可能 |
| `main`(使用キャラ) | ほぼ全員 | ○ 使用可能 |
| `country`(国籍) | 全員 | ○ 使用可能 |

**正直にお伝えします**: 「読み合いが上手い」「コンボが参考になる」のような**質的な学習価値の分類は、現状のデータではときど選手1名分しか実現できません**。この分類を全選手に広げるには、`learningCategories`データの追加入力という**データ整備作業そのものが必要**になり、今回の「見せ方の改善」の範囲を超えます。

### 現実的な代替案

`style`(38%)・`achievements`(ほぼ全員)・`main`・`country`という**実際に広くカバーされているデータだけ**で、以下の分類は可能です。

- 🏆 大会実績が豊富(`achievements.length`) — 全選手対象
- ⚡守りが堅い/攻めが得意(`style`のキーワード判定) — 該当データがある約35名のみ対象
- 🇯🇵日本トップ/🌍世界トップ(`country`) — 全選手対象
- 🎮このキャラの使い手(`main`) — 全選手対象
- ✨**詳しく学べる選手**(`learningCategories`がある選手のみに表示する特別枠) — 現状ときど選手のみだが、**今後データが追加されるたびに自動的に増える設計**にしておく

## ■追加問題点

1. キャラクター詳細ページが「情報を読んで終わり」になっており、**練習・動画・対策・プロ・FAQへの行動が、ユーザー自身がスクロールして探さないと見つからない**
2. プレイヤー詳細ページの「使用キャラ」は**テキスト表示のみでリンクになっていない**(確認済み)ため、キャラクター図鑑への接続が完全に断たれている
3. 「誰から学ぶか」という価値提示は、**データが乏しいため大規模な実現は困難**という制約を先に共有する必要がある

## ■追加改善案: 行動導線設計

### 共通の設計思想

各ページの**末尾に「次にすること」ブロックを新設**し、閲覧後の自然な行動を2〜4個の具体的な選択肢として提示します。これは新しいデータを必要とせず、**既存ページ間のリンクを「導線」として意図的に再配置するだけ**で実現できます。

### キャラクター詳細ページの行動導線

```
[ページ末尾に新設: 「次にすること」]

- 🎯 このキャラを練習する           → training.html
- 🛡 対策を見る(苦手キャラの場合は強調) → ページ内「有利不利」セクションへアンカー、または対策動画タブへ
- 👤 ○○を使うプロを見る             → players.html?main=このキャラID(新規: URLパラメータでの絞り込み)
- ▶ おすすめ動画を見る              → ページ内動画タブへアンカー
- ❓ 関連FAQを見る                  → 既存のpickDailyFaq()のキーワード判定を流用し、「コンボ/対策/練習」関連FAQを1件表示
```

このキャラが**お気に入り登録済みなら「引き続き使い込む」トーン**、**苦手登録済みなら「対策を優先」するトーン**に文言を出し分けることで、既存のお気に入り/苦手データをここでも活用します(新規データ不要)。

### プレイヤー詳細ページの行動導線(使用キャラからの連鎖)

```
使用キャラ: JP
  ↓ (クリック)
JPのキャラクター詳細ページへ
  ↓ (character.htmlに新設した「次にすること」導線)
JPのコンボ動画を見る / JPを練習する
```

現状「使用キャラ」がテキストのみで**リンクになっていない**のを、リンク化するだけでこの連鎖が成立します。追加の新規開発は不要です。

### キャラクター図鑑トップの行動導線

一覧を見た後、ユーザーは大抵「1〜2体に興味を持った状態」です。ページ末尾(一覧の下)に、**軽い後押しの1文+CTA**を追加します。

```
「気になるキャラは見つかりましたか？」
[診断でキャラとの相性を見る]  (未診断の場合)
[練習メニューを見る]          (診断済みの場合)
```

### プレイヤー図鑑トップの行動導線

```
「参考になる選手は見つかりましたか？」
[お気に入りに登録した選手をマイページで確認]
```

## ■導線設計(全体像)

```
キャラクター図鑑(一覧)
   ↓ 興味を持つ
キャラクター詳細
   ↓ 「次にすること」
   ├→ 練習メニュー(training.html)
   ├→ 対策動画(ページ内)
   ├→ このキャラを使うプロ(players.html、mainフィルター)
   │     ↓
   │  プレイヤー詳細
   │     ↓ 使用キャラリンク
   │  キャラクター詳細(別キャラ、循環)
   ├→ 関連FAQ(faq.html)
   └→ お気に入り/苦手登録(既存)
         ↓
      マイページ(今日のおすすめに反映、既存)
```

このように、**図鑑を起点に練習・動画・FAQ・他プレイヤー・マイページへ回遊し、最終的にマイページの「今日のおすすめ」に戻ってくる循環**を設計します。新しいページ・新しいデータは一切増やさず、**既存ページ同士の接続を強化するだけ**です。

## ■競合分析: SF6DNAならではの価値

| 比較対象 | 強み | SF6DNAとの違い |
|---|---|---|
| 一般的な攻略サイト | 情報量・網羅性 | SF6DNAは**診断結果・練習履歴という「あなた向け」の文脈**を持てる点が異なる |
| ゲームWiki | 中立的な事実の蓄積、コミュニティ編集 | SF6DNAは**個人の成長を軸にした一貫した物語**(診断→練習→図鑑→マイページ)を作れる点が独自 |
| YouTube(動画そのもの) | 実際の試合・解説の質 | SF6DNAは動画を**「探す」のではなく「自分に必要な形で届ける」**ハブとしての価値がある |
| プロゲーマー紹介サイト | 選手個人のファン向けコンテンツの深さ | SF6DNAは選手を**「学びの対象」として図鑑内に位置づけ**、キャラクター・練習と接続できる点が独自 |

**結論**: SF6DNAならではの価値は、「情報の量」ではなく**「あなたの診断結果・練習履歴・お気に入りを軸に、図鑑の見え方そのものが変わる」**という個人化にあります。今回設計した行動導線(次にすること)は、この価値を実際の画面上で体感させるための仕組みです。

## ■UI: 5秒ルールでのセルフレビュー

- **キャラクター一覧**: 検索・フィルターが最上部にあり、5秒以内に「探す」行動には入れます。ただし**探した後の行動(次にすること)が今回追加するまでは存在しない**ため、5秒ルールは「入口」のみ合格、「出口」は不合格でした
- **キャラクター詳細**: ヒーロー直後に情報セクションが続くため、5秒では「情報を読む」以外の選択肢が見えません。**末尾の「次にすること」を新設することで、スクロールした先に必ず選択肢がある状態**を作ります
- **プレイヤー詳細**: 現状、5秒で分かるのは「この人が何者か」までで、**「だからどうすればいいか」までは分かりません**。使用キャラのリンク化により、5秒後の次の一手が明確になります

## ■重要な補足(正直な報告)

「誰から学ぶか」という当初のご要望を完全に満たすには、**`learningCategories`データを他の選手にも拡充する**という、実装ではなくデータ整備の作業が別途必要になります。これは今回のPhase6のスコープ(見せ方・導線の改善)とは性質が異なるため、**別タスクとして切り出すことを推奨します**。今回の設計では、少ないデータでも破綻しない(1名でも自然に見える)UIとして設計しました。
