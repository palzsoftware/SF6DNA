# Beginner Media Shot List

録画は任意。1テーマ1操作、5〜10秒程度を目安、16:9、余計な待機・メニュー移動を除く。キャラ・操作タイプ・ゲームバージョン・ボタン設定を記録。完成素材の採用は後続Batchで照合後に行う。

| Slot ID | 撮る操作 | 見せたい内容 |
|---|---|---|
| guard | 同じ打撃を立ち／しゃがみでガード | 中段・下段の違いが分かる組み合わせを確認して使用 |
| anti-air | ジャンプを対空で迎撃 | キャラと使用技を記録 |
| impact | 相手DIに後からDI | 行動可能な状態で返す |
| parry | 相手の打撃をパリィ | 攻撃を受け止める様子 |
| rush | パリィの構え→前2回 | 移動と入力履歴 |
| cancel-rush | 対応通常技を当てる→前2回→次の攻撃 | 技から移動する違い。連続ヒットを主張する場合は成立確認 |
| super | 任意SAを1回 | SA種類・キャラ・入力を記録 |
| combo | 使用キャラの短いゲーム内トライアル | 実際に連続ヒットする1レシピ |

個人情報・オンライン相手名は映さない構成を推奨。音声・BGM不要。WHIFF/HIT二種は必須ではない。録画がなくても図解で学習可能。
