## 次回の検証順

1. 行なしが2〜5件のキャラクターを、現行公式コマンドリストまたは実機で個別確認する。
2. 公式Source relationがある41件は、Modern入力を直接記載しているかSource本文を確認する。
3. Modernで直接出せない派生・強度・挑発等は「欠損」と断定せず、行なしのまま理由を記録する。
4. 確認できた値だけを既存migration・重複・Patchと照合して追加する。

P2-01は不足状況整理まで前進したが、一次情報・実機確認によるcoverage向上をまだ行っていないため完了扱いにしない。
