# Ver.1.1 AI Coach Answer Composer Copy Boundary

| Evidence class | User-facing status | Allowed claim |
|---|---|---|
| Verified game fact + verified | 検証済み | Exact verified statement, with original Source/Patch |
| Source-backed fact | 出典あり・検証状態は別管理 | Source-backed statement; never upgraded to verified |
| Unverified candidate | 未確認・追加確認が必要 | Candidate only, with caution |
| Player statement | 本人の入力・発言 | Attribution to user input, not objective fact |
| AI inference | AIによる分析（推定） | Explicit inference only |
| Observed evidence | 観察情報 / 確認済み観察 | Observation only, without game-fact promotion |

Persona wording may alter the lead and order, but not factual text or provenance. Conflicting sources are described as unresolved. Stale or unknown Patch compatibility always receives caution. Source actions describe the destination when metadata is conclusive and otherwise use `情報源を見る`.
